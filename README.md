# IoT-Enabled Smart Asthma Monitoring System

This project presents an IoT-enabled smart mask for real-time asthma risk monitoring using TinyML.

## Features
- Multi-sensor data (PM2.5, MQ-135, DHT11, MAX30102, MAX9814)
- Bi-LSTM + CNN TinyML model
- Edge deployment on Seeed Studio XIAO ESP32C3
- Flask web dashboard for real-time monitoring

## Files
- model.h → TinyML model
- app.py → Flask web application
- dataset.csv → 

## Usage
1. Upload model to ESP32C3
2. Run Flask app:
   python app.py
3. View dashboard in browser
